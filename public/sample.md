# Awesome Web History (a README that has quietly rotted)

A reading list for a talk about the early social web, last updated in 2014.

## Still standing
- [Link rot on Wikipedia](https://en.wikipedia.org/wiki/Link_rot): what this talk is about.
- Source code lives on [GitHub](https://github.com/).
- Reference docs: <https://developer.mozilla.org/>
- The original HTML5 draft: https://www.w3.org/TR/2009/WD-html5-20090825/

## Tools we used
- Mashups were built with [Yahoo! Pipes](https://pipes.yahoo.com/pipes/).
- Firefox extensions used the [Add-on SDK](https://developer.mozilla.org/en-US/Add-ons/SDK).
- Our photo archive was on [Picasa Web Albums](https://picasaweb.google.com/).
- We read every feed in [Google Reader](https://www.google.com/reader/).

## Cautionary tales
- File sharing at scale: http://www.megaupload.com/.
- Real-time collaboration before its time: [Google Wave](https://www.google.com/intl/en/landing/wave/)
