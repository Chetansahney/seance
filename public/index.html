    How the ritual works

    1. Summon. Every http(s) link in your text is found: Markdown, HTML or bare.
    2. Check the pulse. Each link is knocked on politely (HEAD, then GET), at most two at a time per site.
    3. Bury the dead. 404s, 410s, vanished domains, timeouts and failing servers go in the ground. Locked doors (403, 429) stay in the fog: we never call a link dead without proof.
    4. Resurrect. For each dead link, Séance asks the Wayback Machine for its last healthy snapshot, never an archived copy of the 404 page.
    5. Exorcise. Download your document with dead links rewritten. Or run node bin/seance.js README.md --fix, or add the Séance GitHub Action to fail pull requests that add dead links.
